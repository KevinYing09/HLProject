## System challenge: Identify the process, feature, or decision that requires meaningful computation.
Features like the calendar, volunteer data, etc. would require meaningful computation to make any data presentable and organized for users.
## Inputs and outputs: State what information enters the process and what it must produce.
Organizers would enter information regarding what events they have upcoming as well as any other nonprofit related information. Volunteers would enter their information to sign up for various events. The program should output event information to a public gallery of upcoming nonprofit events. Volunteer data should enter some database or other data storage method that is easily readable for organizers.
## Possible structure: Identify relevant classes, collections, algorithms, files, APIs, or data relationships.
* Relevant classes would include Organizer, Volunteer, and Event
* APIs may include database applications like Google's Firebase
* Collections would include events, volunteers, materials, etc.

* See if the chatbot can respond to questions accurately without breaking.
