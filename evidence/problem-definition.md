## User or client: Who might use this solution?
* Nonprofit Organizations
* Volunteers
* Organizers 
## Problem: What difficulty, inefficiency, or unmet need exists?
Nonprofit organizations rely on volunteers and organizers to run their activities. Managing volunteer lists, supplies, and schedules can be very annoying. 
## Proposed solution: What could the program allow the user to do?
The program should allow volunteers to be able to sign up and drop volunteer events easily and should allow organizers and organizations to be able to see who is signed up for various events, what their inventory is like, what their schedule is like, and any other information they need to make the process more efficient.
## Success criteria: Write four to six specific, testable statements.
* Does signing up for an event show your name on the organizer side
* Does the program display proper inventory availability
* Does the calendar load events easily and in a readable manner
* Are records stored properly
## Investigation: Identify one question you must research or ask the intended user.
* What is the biggest issue that impacts the efficiency of your organization?
