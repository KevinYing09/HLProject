# Kevin Ying HLProject Nonprofit Organizer
Pathway: IB HL \
User: This application will be used by organizers of nonprofit organizations and their volunteers \
Problem: This project aims to address the issue these organizations have with ensuring they aren't overlapping events, making sure they know who will attend, etc. \
Features: Gallery of events for volunteers to attend, Sorted data of materials, volunteers, etc. for organizations, Interactive Q&A for questions on either side \
Question: How do I make one application look completely different for two users?
